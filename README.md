# Battle Tracker

A common operational picture in the browser for **unclassified exercise, training and simulation data**. People subscribe to
feeds and upload files in NATO and common formats (STANAG 4607 GMTI, STANAG 4609 motion-imagery KLV, STANAG 4545 NSIF,
STANAG 4676 tracks, STANAG 5527 NFFI, Cursor on Target, NVG, KML/KMZ, GeoJSON, CSV, AIS), and see everything on one live
map in MIL-STD-2525C / APP-6B symbols, with a replay timeline. "Metallic forge" look. Built on [Anvil](https://anvil.works).

- **App repo:** github.com/arkulinskis/battle-tracker (branch `master`). Anvil pulls `master`.
- **Live:** https://battletracker.anvil.app

## What it does

**For visitors:** a landing page (promise, the 11 formats, how it works, who it's for, FAQ, the not-for-operations note),
sign-up with email and password, feedback form, Privacy & Terms (`#legal`).

**Map** (`#map`, home):
- Every subscribed feed on one Leaflet map. Units and tracks in MIL-STD-2525 symbols (milsymbol), GMTI dots fading with age,
  radar dwell wedges, FMV sensor footprints and frame-centre tracks, phase lines, objectives, range fans, image footprints.
- Tracks (same id across drops) show their newest position plus a trail; reports older than 2 hours dim.
- **Timeline:** drag to replay from the oldest to the newest data, play at 10×–1200×, LIVE follows new data.
- **Layers panel:** the picture's count (friend / hostile / neutral / unknown / movers), feeds on/off (remembered),
  labels (shown from zoom 12), trails, symbol size, the time window for movers and footprints. **Tracks tab:** search and jump.
- **Inspector:** click anything: SIDC decoded (identity, dimension, function, echelon, modifier), MGRS + lat/lon, time as a
  Zulu date-time group, track speed and bearing, every reported property, the source file. Centre, follow, remove a plot.
- Base maps (Forge dark, Steel light, Terrain, Imagery), cursor MGRS readout, measure distance + bearing (degrees and mils).
- Classification banner from the visible feeds' markings. Polls every 20 s and reloads quietly when a feed has new data.

**Feeds** (`#feeds`, `#feeds/<id>`):
- Catalogue: your subscriptions, your feeds, public feeds to discover; search by name or format; join a private feed with its
  invite code; create a feed (name, description, public/private, unclassified marking, colour).
- Feed page: stats, drops (each file, push or plot) with a preview map and the file's summary; owners get the **push endpoint**
  (`POST /_/api/ingest/<key>` with CoT XML or GeoJSON, curl example, a "try a push" box, new key), the invite code, settings, delete.

**Upload** (`#upload`, `#upload/<feedId>`): drop files (several at once, 4609 video in 8 MB slices up to several GB); the format
is detected and parsed **in the browser**; each file shows its summary (packet headers, KLV fields, NITF header…), warnings
and a preview map, then is published to one of your feeds. Files marked above UNCLASSIFIED are refused. **Samples** for all
11 formats are generated byte for byte in the browser (shift-click downloads them).

**Symbols** (`#symbols`, `#symbols/<SIDC>`): build a symbol (identity, dimension, function, echelon, HQ/TF/dummy, status,
designation, higher formation), copy its SIDC, browse the gallery per dimension, decode any letter or 2525D/E number SIDC,
**place it on the map** (into your private "My plots" feed).

**For admins** (`#admin`; arkulinskis@gmail.com becomes an admin on first sign-in):
- **Overview** counts, **Feeds** (every feed incl. private; feature public feeds, delete), **Feedback inbox**, **Users**,
  **Demo data** (the fictional exercise IRON ANVIL 26 at Camp Pendleton: 8 feeds, 4 demo people; remove or reload).
- Featured public feeds are subscribed automatically the first time someone opens the map.

## Setting it up in Anvil (once)

1. In the Anvil editor: **Create app → Clone from GitHub**, and paste `https://github.com/arkulinskis/battle-tracker`.
2. **Users** service: email + password, sign-up allowed (already set in `anvil.yaml`; check it).
3. Open the app in the editor. If it shows a **Schema Mismatch** alert, choose **"The schema of the source code is correct"** so Anvil creates the tables.
4. **Run** it and sign up with **arkulinskis@gmail.com** straight away (that account becomes the admin).
5. **Publish** (Publish → public URL, or your own domain).

## Working on it

See `.claude/skills/battletracker/SKILL.md`. In short:

```
python -I tools/check.py --ui                    # syntax, server tests, headless UI tests → ALL CHECKS PASSED
python -I tools/preview/devserver.py 8765        # the app on in-memory data: http://localhost:8765/  (?as=ana#map, ?as=admin#admin)
python tools/deploy.py                           # dry run (needs PyYAML, so no -I)
python tools/deploy.py --push "Message"          # deploy: commit + push to GitHub, Anvil pulls it
```

## Project layout

```
web/            core.js/core.css (engine + forge tokens), app.js (header, footer), pages/*.html
web/pages/_bt.html       BT helpers: SIDC catalogue + decoder, milsymbol cache, MGRS, DTG, base maps, drawing features

web/pages/_samples.html  sample-file writers for every format
client_code/    Main.py (the only Anvil form: bridge to the server, sign-in), legal.py
server_code/    Feeds.py, Drops.py (cleaning + storing), Tactical.py (the map), Ingest.py (push endpoint), DemoData.py, + template modules
assets/         icon.svg (infantry symbol in molten ember) + generated PNG icons
tools/          sync_to_anvil.py (settings + table schema), deploy.py, check.py, preview/ (dev server, UI tests, screenshots), testing/
```
